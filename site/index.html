How it works

Three steps. No POS integration required.

1

Upload your sales history

Paste your existing spreadsheet — CSV, tab-separated, or just "date: amount" lines. PrepCast auto-detects the columns and builds your baseline.

you: upload_sales_csv "Date,Revenue\n01/06/2026,$6240\n01/07/2026,$4100..."
2

Ask for your forecast

Tell Claude what day it is and any events nearby. PrepCast looks at your day-of-week baseline, recent trend, and event multiplier to project revenue.

you: forecast_sales for Saturday, volleyball tournament 6000 people
3

Get your prep list

Run generate_prep_list with the projection. Every item — patties, bacon, buns, hot dogs, grilled cheese — with quantities and case counts. Log actuals at end of day and the model gets smarter.

you: generate_prep_list projected_revenue=7420 buffer_pct=15

All 12 tools

Each one does exactly one thing. Nothing bloated.

Sales Data
upload_sales_csv Import historical spreadsheets. Auto-detects columns.
log_daily_sales Log today's actual revenue at end of day.
get_sales_summary How much history is loaded, date range, averages.
Forecasting
forecast_sales Project revenue for any date with event adjustments.
analyze_history Day-of-week patterns, best/worst days, trends.
Prep Lists
generate_prep_list Full item quantities from projected revenue + buffer.
update_menu_ratios Calibrate ratios to your store (bacon split, cases, etc.)
get_menu_ratios Review current ratios and adjust.
Events
get_upcoming_events Fetch events at nearby venues with traffic multipliers.
log_event_outcome Record actual sales on event days. Model learns.
get_event_multipliers See learned multipliers per event type (volleyball, etc.)

Get started in 2 minutes

Add PrepCast to Claude Desktop or any MCP client.

1

Add to Claude Desktop config

Open ~/Library/Application Support/Claude/claude_desktop_config.json and add:

{
  "mcpServers": {
    "prepcast": {
      "command": "python",
      "args": ["/path/to/prepcast-mcp/server.py", "--stdio"],
      "env": {
        "PREPCAST_DATA_DIR": "/path/to/your/data"
      }
    }
  }
}
2

Install dependencies

$ git clone https://github.com/Bbadhub/prepcast-mcp

$ cd prepcast-mcp && pip install -r requirements.txt

$ python server.py --stdio

3

Or run with Docker

$ docker-compose up -d

# SSE server on port 8420
